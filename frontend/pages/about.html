Architecture & Engineering

About WeatherSphere

"Weather, wherever you are." A professional, high-performance full-stack meteorological platform built with Vanilla web standards and robust Node.js REST services.

Project Overview

WeatherSphere delivers hyper-local atmospheric forecasts, real-time observational metrics, and 7-day extended projections across every city worldwide. Built with strict adherence to architectural decoupling, zero frontend framework bloat, and enterprise security practices.

The system employs a multi-tiered architecture that keeps all API keys strictly enclosed inside the Express backend proxy layer, completely preventing credential exposure to client browsers.

Secure Decoupled Architecture

Browser Client (HTML5 / Vanilla JS / CSS3)
  │
  ▼ (JSON Fetch Requests with JWT Bearer Token)
Express.js REST API Gateway (Port 5000)
  ├── Authentication Middleware (JWT Validation & bcryptjs)
  ├── Weather & Geocoding Services (Key Protection Proxy)
  └── Data Access Layer (Mongoose & MongoDB Models)
  │
  ▼ (Encrypted HTTPS External Calls)
OpenWeather API & Global Weather Satellites

REST API Endpoints

Method Endpoint Auth Description
GET /api/health Public System health and API status
GET /api/weather?city=Jaipur Public Normalized current weather by city name
GET /api/weather/coordinates?lat=...&lon=... Public Normalized weather by latitude and longitude
GET /api/forecast?city=Jaipur Public 24-hour hourly and 7-day daily forecast
POST /api/auth/register Public User registration with bcrypt hashing
POST /api/auth/login Public User login returning JSON Web Token
GET /api/favorites JWT Get user's favorite cities
DELETE /api/history JWT Clear all user search history

Privacy Guarantee

Your geographic coordinates are utilized strictly on-demand for weather retrieval. Coordinate data is never sold or shared with external tracking ad-networks. Passwords are irreversibly hashed with salted bcrypt rounds.
